# NGA 清漪 · 阅读界面设计提案

打开 [index.html](./index.html) 可切换手机列表、竖屏阅读、手机横屏阅读、折叠双栏、网页登录五个视图与明暗主题。本目录是可浏览的本地设计稿，不是运行中 App 的截图，也不修改 Android 产品代码。所有帖子标题、作者和正文都是排版示例；设计稿不联网、不存储或发送用户数据。

## 设计方向

- 内容采用冷白／近黑阅读纸面、连续行和细分隔。标题、作者、最后回复时间、回复数来自现有主题模型，不添加摘要、点赞等未实现字段。
- 导航和少量操作浮层使用半透明玻璃、细亮边与层次阴影；正文、列表和网页登录视口不用玻璃。顶部操作分成独立控制，底部 dock 与页面边缘保持距离。
- 帖子阅读只在主楼显示主题标题。作者、时间、楼层及回复内容构成连续阅读流；右下角浮岛只占自身宽度，不产生固定底栏。手机横屏也使用同一紧凑操作组。正文末尾留有滚动空间，使最后一行可滚出浮岛覆盖区。
- 折叠内屏将列表和当前帖子并排，选中行与正文保持同一纸面秩序。系统状态栏在顶部单独占位；左侧 N 标识及三个导航控件组成一组，位于剩余高度的中央，短窗口时导航轨可滚动。网页登录让内嵌网页占据主体，刷新和检测登录状态始终可达，帮助收进底部 sheet。

## 能力边界

设计稿参照现有 `ThreadListScreen`、`PostScreen`、`LoginScreen` 与 `ThreadItem`、`Post` 模型。原生版块收藏、主题收藏、搜索、发主题、精华筛选、子版块、排序、只看楼主、翻页、回复、网页刷新和登录状态检测均已有对应能力。稿中的导航切换、明暗切换和登录帮助 sheet 可交互；其他控件展示布局位置，不执行 NGA 操作。网页登录区域是标注清楚的占位区域，不模拟 NGA 的账号密码或扫码页面。

HTML 的 `backdrop-filter` 仅演示目标外观。Android 端若实施这一方向，需要为不支持实时背景模糊的系统版本保留清晰的不透明或半透明表面；本提案没有宣称该效果已经在 App 中实现。

`render_previews.py` 仅是本地截图辅助脚本，使用现有 Edge 与 Python `websockets` 调用浏览器截图接口，对设备 DOM 元素直接截图；设计稿页面本身没有运行时依赖。浏览器测得竖屏及手机横屏浮岛为 173×56 CSS 像素，两个图标触点为 44×44，回复触点为 69×44；折叠内屏浮岛为 148×56，三个触点均为 44×44。这些是设计稿 DOM 尺寸，不代表原生 App 已采用相同 dp 尺寸。

折叠稿的浏览器 DOM 测量显示：状态栏底边在页面 y=215，导航组顶部 y=440；导航组中心与状态栏下方导航轨中心相同（y=543.5）。三个轨道按钮均为 44×44 CSS 像素。这一留空关系直接显示在设备截图中。
