CONTINUOUS THREAD

一个标题，
接着读下去。

主楼承担一次标题展示；回复从细线之后自然续接。操作 dock 悬在阅读区底部，内容滚动范围预留超过 dock 的空间。

  • 楼层号和作者在同一信息行
  • 只看楼主、翻页、回复均可达
  • 楼层操作保持独立入口
LANDSCAPE READING

横屏仍是阅读区，
操作只占一角。

内容从顶部连续滚到底，右下角三项操作保持触控面积。浮岛不创建整行底栏，正文末尾另留足够滚动空间。
