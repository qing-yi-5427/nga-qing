## 已验收边界与未实测范围

最终包保数据安装、冷启、四 Tab/搜索/历史与两轮第 5 楼即时续读已在实体直板机复验；离线中文提示、回复编辑器 IME 与短横屏滚到底的实体证据来自生产源码相同的最终 Debug 候选，未输入/发送内容。系统字体 1.3/1.5 与六尺寸预设因为 HyperOS 拒绝标准设置/显示覆盖命令，只由 Compose/Robolectric 渲染和策略测试覆盖；**实体折叠、铰链遮挡、打开/合起连续性均未验证**。TalkBack 与私密账号流程另按 [验收矩阵](validation.md)标边界。

初稿曾发现大标题、搜索、续读卡、讨论容器、收藏层级、Reader 顶栏和旧 rail 明显偏离 HTML；这些是当时已解决的设计迭代问题，不再作为当前阻断清单。新包如再改布局，应重新审相应原尺寸样图及真实窗口，避免沿用旧图结论。
